# Agent Instructions

## Repository structure

Two independent projects, no shared workspace config:

- **Root (`/`)** — Backend API: Express + TypeScript + Prisma + SQLite
- **`abricot/`** — Frontend: Next.js 16 + React 19 (App Router)

They have separate `package.json`, `node_modules`, and `tsconfig.json`. Run commands from the correct directory.

## Backend (root)

### Commands

```bash
npm install          # install deps
npm run dev          # start dev server (nodemon + ts-node, port 8000)
npm run build        # tsc → dist/
npm run seed         # populate DB with test data (ts-node scripts/seed.ts)
npx prisma generate  # regenerate Prisma client after schema changes
npx prisma migrate dev  # create new migration
npx prisma db push   # push schema without migration file
npx prisma studio    # visual DB browser
```

No test framework is configured. No lint or typecheck commands exist beyond `tsc`.

### Key facts

- Entry point: `src/index.ts`
- Database: SQLite at `prisma/db.sqlite` (gitignored)
- Auth: JWT via `src/middleware/auth.ts`, secret in `.env` (`JWT_SECRET`)
- Path alias: `@/*` maps to `src/*`
- ORM: Prisma client singleton at `src/lib/prisma.ts` — always import from here, never instantiate directly
- Roles: Owner, Admin (`ADMIN`), Contributor (`CONTRIBUTOR`) on `ProjectMember`
- Task statuses: `TODO`, `IN_PROGRESS`, `DONE`, `CANCELLED`
- Swagger docs served at `/api-docs` when server is running
- CORS allows `localhost:8000` and `localhost:8001` in dev

### Conventions

- French variable names and comments throughout (this is a French-language project)
- Error responses use `{ success: false, message, error }` shape
- Success responses use `{ success: true, ... }` shape
- Controllers handle business logic, routes are thin wrappers
- `src/types/` contains shared TypeScript interfaces

## Frontend (`abricot/`)

### Commands

```bash
cd abricot
npm install
npm run dev    # Next.js dev server (port 3000)
npm run build  # production build
npm run lint   # eslint
```

### Key facts

- App Router at `abricot/src/app/`
- Next.js 16.3.5 — read `node_modules/next/dist/docs/` before writing Next.js code; APIs may differ from training data
- `abricot/AGENTS.md` is auto-generated by `next dev` — do not delete or edit manually
- `abricot/CLAUDE.md` just references `@AGENTS.md`

## Gotchas

- No `.env.example` exists — copy `.env` structure from README if setting up fresh
- `figma_data.json` and `figma_data1.json` at root are Figma export data, not code
- Backend `"test"` script is a placeholder (`echo "Error: no test specified"`)
- Prisma migrations are in `prisma/migrations/` — check before creating new ones
